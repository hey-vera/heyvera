API Reference

ClawNet is a sovereign AI agent orchestration layer. All API endpoints are available at https://api.claw-net.org. The API uses JSON for all requests and responses.

Base URL
https://api.claw-net.org
Auth Header
X-API-Key: your_key
Rate Limit
60 requests per minute per IP
Credits
1 credit = $0.001. Buy via Stripe or USDC.

Authentication

ClawNet supports two authentication methods. Most endpoints require an API Key. Some endpoints additionally support Clerk JWT for browser-based flows.

Header X-API-Key

Include your API key in every request. Obtain your key from the dashboard after purchasing credits.

curl https://api.claw-net.org/v1/auth/me \
  -H "X-API-Key: cn_your_api_key_here"
Header Authorization: Bearer {token}

Alternatively, use a Clerk JWT session token obtained from window.Clerk.session.getToken() in browser contexts.

Errors

All errors return a JSON object with an error field and appropriate HTTP status codes.

CodeMeaning
400Bad Request — invalid parameters
401Unauthorized — missing or invalid API key
402Payment Required — insufficient credits
403Forbidden — you don't own this resource
404Not Found
409Conflict — duplicate idempotency key or already starred
429Too Many Requests — rate limit exceeded
500Internal Server Error
 
{ "error": "Insufficient credits", "creditsRequired": 5, "creditsAvailable": 2 }

Rate Limits

The API enforces a limit of 60 requests per minute per IP address. When exceeded, the API returns HTTP 429. Rate limit headers are included in all responses.

HeaderDescription
X-RateLimit-LimitMax requests per window
X-RateLimit-RemainingRequests remaining in current window
X-RateLimit-ResetUnix timestamp when window resets

Orchestration

Submit natural language queries. The orchestration layer automatically selects APIs, fetches data, and returns a structured answer.

POST /v1/orchestrate

Submit a query and receive an orchestrated answer. Credits are deducted based on APIs used.

Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
querystringYesNatural language query (max 2000 chars)
contextobjectNoAdditional context passed to the orchestrator

Example Request

curl -X POST https://api.claw-net.org/v1/orchestrate \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"What is the current SOL price and top holder distribution?"}'

Example Response

{
  "answer": "SOL is trading at $180.42...",
  "sources": ["price-oracle", "whale-tracker"],
  "creditsUsed": 8,
  "durationMs": 1840
}

Batch Orchestration

POST /v1/batch

Submit up to 10 queries in parallel. Each query is billed separately. Results are returned as an array in the same order.

Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
queriesstring[]YesArray of query strings (max 10)

Example Request

curl -X POST https://api.claw-net.org/v1/batch \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"queries":["SOL price?","ETH gas?","BTC dominance?"]}'

Streaming

GET /v1/stream/orchestrate

Server-Sent Events (SSE) stream. Emits events as the orchestrator works: start, plan, step, done, error.

Requires: X-API-Key (query param or header)

Query Parameters

NameTypeRequiredDescription
querystringYesThe query to stream
apiKeystringNoAPI key as query param (alternative to header)

Example

const es = new EventSource(
  'https://api.claw-net.org/v1/stream/orchestrate?query=SOL+price&apiKey=YOUR_KEY'
);
es.onmessage = (e) => console.log(JSON.parse(e.data));

Skills

Skills are prompt-powered AI services. Publish a skill to the marketplace and earn 97% of every purchase.

POST/v1/skills

Create and optionally publish a new skill.

Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
namestringYesUnique slug (lowercase, hyphens, max 64)
displayNamestringYesHuman-readable name
descriptionstringYesWhat the skill does
promptTemplatestringYesPrompt with {{variable}} placeholders
creditCostnumberYesPrice in credits (0–10000)
publicbooleanNoList in marketplace (default: false)
tagsstring[]NoUp to 10 tags
categorystringNodefi, security, social, ai, search, media, enrichment, analytics, infrastructure, utility, weather, general
versionstringNoSemver (default: 1.0.0)
changelogstringNoWhat's new in this version
readmestringNoDetailed usage guide
 
curl -X POST https://api.claw-net.org/v1/skills \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "token-sentiment",
    "displayName": "Token Sentiment",
    "description": "Analyze social sentiment for any token",
    "promptTemplate": "Analyze the social sentiment for {{token}} on Twitter and Reddit.",
    "creditCost": 3,
    "public": true,
    "category": "social"
  }'
GET/v1/skills/mine

List all skills owned by the authenticated key.

Requires: X-API-Key
GET/v1/skills/:id

Get full details of a skill by ID. Public skills are accessible without auth.

POST/v1/skills/:id/invoke

Invoke a skill you own for free (no credit charge). Purchased skills can also be invoked this way.

Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
variablesobjectNoKey-value pairs for template variables
PATCH/v1/skills/:id/visibility

Toggle a skill between public (listed in marketplace) and private (draft).

Requires: X-API-Key (must own skill)

Body

{ "public": true }
DELETE/v1/skills/:id

Permanently delete a skill. Cannot be undone. All associated purchase history is retained.

Requires: X-API-Key (must own skill)
GET/v1/skills/:id/metrics

Get performance metrics for a skill: success rate, avg duration, total uses, revenue.

Requires: X-API-Key (must own skill)

Tasks

Tasks represent asynchronous skill executions. Each marketplace purchase creates a task. Tasks can be listed, inspected, cancelled (if pending), and rated (when completed).

POST/v1/tasks

Submit a task for execution. Deducts credits atomically. Returns the task result when complete or a task ID for async polling.

Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
skillIdstringYesThe skill to execute
variablesobjectNoTemplate variable values
idempotencyKeystringNoPrevent duplicate execution (max 128 chars)
webhookUrlstringNoURL to POST results to when complete
 
curl -X POST https://api.claw-net.org/v1/tasks \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "skillId": "token-analysis",
    "variables": {"token": "SOL"},
    "idempotencyKey": "req_abc123"
  }'

Response

{
  "taskId": "tsk_abc123",
  "status": "COMPLETED",
  "result": { "answer": "SOL analysis..." },
  "costCredits": 5,
  "durationMs": 1240
}
GET/v1/tasks

List your task history, paginated. Includes status, credits charged, and duration.

Requires: X-API-Key

Query Parameters

NameTypeRequiredDescription
limitnumberNoResults per page (default: 20, max: 100)
offsetnumberNoPagination offset
GET/v1/tasks/:id

Get full detail of a single task including result and error if any.

Requires: X-API-Key (must own task)
POST/v1/tasks/:id/cancel

Cancel a task in PENDING status. Credits are refunded if not yet consumed.

Requires: X-API-Key (must own task)
Only PENDING tasks can be cancelled. RUNNING or COMPLETED tasks cannot be cancelled.
POST/v1/tasks/:id/rate

Rate a completed task. Rating contributes to the skill's reputation score.

Requires: X-API-Key (must own task)

Body Parameters

NameTypeRequiredDescription
ratingnumberYes1–5 stars
commentstringNoOptional written feedback
 
curl -X POST https://api.claw-net.org/v1/tasks/tsk_abc123/rate \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"rating": 5, "comment": "Accurate and fast"}'

Marketplace

Browse, purchase, and star skills. Creators earn 97% of every purchase. The 3% platform fee funds infrastructure and treasury.

GET/v1/marketplace/skills

Browse the public skill catalog. Supports search, category filter, and sorting.

Query Parameters

NameTypeRequiredDescription
pagenumberNoPage number (default: 1)
limitnumberNoPer page (default: 12, max: 50)
sortstringNopopular, stars, newest, price_asc, price_desc, reputation
searchstringNoFull-text search
categorystringNoFilter by category
GET/v1/marketplace/skills/:id

Get full skill detail including cost breakdown, schema, runtime info, and creator stats.

POST/v1/marketplace/skills/:id/purchase

Purchase and immediately execute a skill. Credits are deducted atomically. 97% go to the creator, 3% to the platform treasury.

Requires: X-API-Key
Self-purchase is blocked. You cannot buy your own skills.

Body Parameters

NameTypeRequiredDescription
variablesobjectNoTemplate variable values
 
curl -X POST https://api.claw-net.org/v1/marketplace/skills/token-analysis/purchase \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"variables": {"token": "SOL"}}'

Response

{
  "answer": "SOL is currently trading at...",
  "creditsCharged": 5,
  "taskId": "tsk_xyz789",
  "durationMs": 980
}
POST / DELETE/v1/marketplace/skills/:id/star

Star (POST) or unstar (DELETE) a skill. Stars affect the skill's popularity ranking.

Requires: X-API-Key
POST/v1/marketplace/skills/:id/report

Request a USDC payout of your earned credits. Minimum 1,000 credits ($0.75). Processed within 48 hours.

Your marketplace transaction history. Includes purchases, earnings, and refunds.

Escrow

Trustless credit escrow for freelance work. Credits are locked until work is approved or disputed.

POST/v1/escrow

Create an escrow. Locks the specified credits until the work is approved.

Requires: X-API-Key

Body

NameTypeRequiredDescription
counterpartyEmailstringYesEmail of the worker
amountnumberYesCredits to lock
descriptionstringYesWork description
timeoutHoursnumberNoAuto-expire timeout (default: 72h)
GET/v1/escrow

List all escrows you are party to (as payer or worker).

Requires: X-API-Key
POST/v1/escrow/:id/submit

Worker submits completed work. Moves escrow to WORK_IN_PROGRESS → awaiting approval.

Requires: X-API-Key (worker only)
POST/v1/escrow/:id/approve

Payer approves the work. Credits are released to the worker immediately.

Requires: X-API-Key (payer only)
POST/v1/escrow/:id/dispute

Either party can open a dispute. Credits are frozen pending resolution. Include a reason.

Requires: X-API-Key

Registry

GET/v1/registry

List all registered API endpoints with category, provider, and description.

GET/v1/registry/health

Live health status for all registered endpoints. Updated every 5 minutes via HEAD requests.

LLM Proxy

GET/v1/llm/models

List all available LLM models with credit cost per 1K tokens.

POST/v1/llm/chat

OpenAI-compatible chat completion. Drop-in replacement for api.openai.com/v1/chat/completions.

Requires: X-API-Key

Generate text embeddings for semantic search and similarity matching.

Mesh

ClawNet runs a libp2p mesh network for peer discovery via Kademlia DHT. Peers are discovered automatically on port 4001.

GET/v1/mesh/peers

List connected mesh peers with peer IDs, multiaddrs, and last-seen timestamps.

Response

{
  "nodeId": "12D3KooW...",
  "listening": ["/ip4/0.0.0.0/tcp/4001"],
  "peers": [{ "id": "12D3KooW...", "multiaddr": "/ip4/...", "last_seen": "2026-03-10T..." }]
}
