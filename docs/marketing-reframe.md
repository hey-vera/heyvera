# AID Protocol — Marketing Positioning (Flaw 17)

## Core Message

**"The only protocol that converts evidence into a portable trust score."**

Not: "a trust layer for agents" (generic)
Not: "identity + payment + trust" (feature list)
Not: "replaces x402" (competitive, wrong frame)

**The right frame:** AID converts verifiable execution evidence (attestations, hash chains, Merkle proofs) into a single portable number (0-100) that any platform can consume. Evidence → Score → Commerce.

## Narrative Arc

1. **The problem:** 1,184 malicious OpenClaw skills got through. No trust layer exists.
2. **The insight:** Every protocol (MCP, A2A, x402, MPP) is missing the same thing — trust.
3. **The solution:** AID — one trust score that works across every protocol.
4. **The proof:** Production code, npm packages, DIF submission, 90+ features built.
5. **The ask:** `npm install @aidprotocol/mcp-trust` — add trust to your server in 1 line.
