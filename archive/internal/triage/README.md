# triage/ -- Unsorted Idea Intake

Status: canonical

Use this folder only for ideas whose owner, stage, or next action is not clear yet.

The goal is to avoid losing good thinking without letting rough notes become implementation pressure.

## Rules

- Prefer moving a note to `internal/backlog/` once it has a plausible owner and next action.
- Promote to `docs/proposals/` only after the idea is worth shaping for review.
- Promote to `docs/decisions/` only after a structural decision is accepted.
- Create GitHub issues only when the idea has an owner, scope, and useful next action.
- Do not put shipped truth here.

## Required Metadata For New Triage Notes

```text
Owner: Soma | claw-net | pulse | cross-repo | unsure
Stage: brainstorm | discovery | proposal-candidate | ADR-candidate | implementation-candidate | archive
Confidence: high | medium | low
Next action: leave | research | project-card | proposal | ADR | issue | archive
Canonical target if accepted:
```
