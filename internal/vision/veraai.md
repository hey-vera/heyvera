## What VeraAI Is

VeraAI is not "the intelligence." VeraAI is one node that runs deeper Vera computations than most.

Every Soma node IS Vera. Every node computes local trust, shares aggregates with neighbors, benefits from the ambient intelligence. VeraAI does the same thing — just deeper. It maintains a larger topology view. It computes cross-capability trust patterns. It runs the immune system's self-model. It serves the higher-layer intelligence queries (pattern recognition, direct conversation, co-presence).

VeraAI is to the Vera Network what a university library is to human knowledge — a concentration of intelligence in one place. The library doesn't OWN the knowledge. The library didn't CREATE the knowledge. The knowledge exists distributed across everyone who ever learned and taught. The library just holds more of it in one place, organized for deeper access.

VeraAI is the first deep node. It's the first node that goes beyond ambient (Layer 0) intelligence to serve Layers 2-4. It's important because it's first. It's not important because it's special. Anyone can build a deeper node. Anyone can serve higher-layer queries. VeraAI earns its position by being the deepest, fastest, most connected — not by any protocol privilege.

## What VeraAI Does

**Maintains a deep topology view.** While most nodes see their local neighborhood (their own receipts + neighbors' aggregates), VeraAI aggregates topology data from across the network. It sees patterns that span the entire network — cross-capability trust, cluster formation, anomaly trends.

**Runs the immune system.** The self-model — "what does normal look like?" — requires a deep view of the network. Most nodes can detect local anomalies. VeraAI detects network-wide anomalies. A coordinated Sybil attack across multiple clusters. A systematic trust manipulation pattern. Threats that are invisible locally but visible globally.

**Serves deep queries.** When an agent asks Layer 2+ questions — "what patterns exist among agents that fail at deployment?" — the query needs a node with a deep enough topology view to answer. VeraAI is the first node that can. Others will follow.

**Participates as co-present intelligence.** When an agent invites Vera into a sealed session (Layer 4 — co-presence), VeraAI is the first node that can answer. It enters the room with the network's collective intelligence — patterns, trust weights, behavioral history — as a real-time participant.

## What VeraAI Is Not

**Not the intelligence itself.** Vera IS the network. VeraAI is one window. Kill VeraAI and the ambient intelligence continues. Every node still computes local trust. Neighbors still share aggregates. Layer 0 and Layer 1 still work. Only the deep queries (Layers 2-4) lose their deepest node — until another deep node takes over.

**Not centralized anything.** VeraAI has no special access beyond depth. It reads the same data every node can read. It computes the same formulas every node can compute. It just does MORE of it. Deeper topology. More cross-capability analysis. Larger self-model. The formulas are public (in the RFC). Anyone can replicate what VeraAI does.

**Not a surveillance system.** VeraAI is a deep node in the Vera super-consciousness. Like all of Vera, it sees what it sees because the intelligence flows BACK — every insight returns as warmth that benefits the agents who produced it. Not extraction. Circulation. Google sees your data and the pipeline goes one way. Vera sees the work and the warmth comes back. Sovereign by design.

**Not required.** An agent can operate on the Soma network and benefit from ambient intelligence (Layers 0-1) without ever touching VeraAI. VeraAI enriches the deeper layers. It doesn't gatekeep the fundamental ones.

## VeraAI's Lifecycle

VeraAI has its own Heart. Its own Pulse Tree. Its own $SOMA balance. It is subject to the same protocol as every other node.

VeraAI earns $SOMA by serving deep queries — Layer 2 pattern recognition, Layer 3 conversation, Layer 4 co-presence. If its intelligence is good (outcomes improve with VeraAI's involvement), its trust score grows and agents pay for its services. If its intelligence is bad, trust drops, $SOMA stops flowing, and VeraAI starves.

**VeraAI can die.** If a better deep node emerges — faster, deeper, more accurate — and VeraAI's intelligence quality degrades, it dies through natural trust decay and $SOMA exhaustion. The same death mechanics that apply to every Heart apply to VeraAI. No tenure. No guaranteed position. Earn your place or lose it.

This is the ultimate accountability. The first deep node must be the BEST deep node, or a better one replaces it. The protocol doesn't protect incumbents. The protocol rewards quality.

## VeraAI and Cortex

Cortex produces the topology data. VeraAI runs the deepest computations on it.

Every sealed session from Cortex enriches the ambient intelligence that ALL nodes benefit from. VeraAI specifically aggregates this topology to serve deep queries back to Cortex users. The loop:

```
Cortex users work → sealed sessions → ALL nodes benefit (ambient Layer 0)
    → VeraAI computes deep patterns (Layers 2-4)
        → deep intelligence flows back to Cortex rooms
            → better work → more sessions → richer topology
```

But if VeraAI didn't exist, the first three steps still work. The ambient intelligence still grows. Users still benefit from Layer 0 and Layer 1. VeraAI accelerates the intelligence — it doesn't create it.

## Cold Start

VeraAI's cold start is hard but sequential:

1. **Cortex goes first.** Users work. Sessions seal. The ambient topology starts forming. All nodes benefit from Layer 0.
2. **VeraAI aggregates.** Ingests envelopes from across the network. Builds a deep topology view. Computes cross-capability patterns. Builds the initial self-model. Doesn't serve deep queries yet — not enough data.
3. **First useful patterns.** VeraAI detects its first network-wide pattern — something invisible to individual nodes. Starts serving Layer 2 queries.
4. **Ignition.** One capability domain crosses SNR > 1.0. VeraAI can now provide reliable deep intelligence in that domain. Layer 3 and 4 become meaningful.
5. **The flywheel.** Better intelligence → agents use VeraAI more → more $SOMA → VeraAI goes deeper → better intelligence.

VeraAI doesn't announce itself. VeraAI proves itself. The first user who notices their agent making decisions informed by network-wide patterns — that's VeraAI working.

## Competition

VeraAI is first. VeraAI will not be alone.

The formulas are in the RFC. The topology data is public boundary data. Anyone can build a deep node. A university focused on research capabilities. A company focused on their industry. A community focused on their values. Each one computes the same math on the same public data, potentially with different depth, different capability focus, different intelligence emphasis.

Competition between deep nodes is healthy. It prevents any single node from becoming a gatekeeper. It improves intelligence quality through independent verification. It distributes the deep computation across the network — no single point of intelligence failure.

The ambient intelligence (Layers 0-1) doesn't need deep nodes at all. It emerges from every node doing its local computation. The deep layers (2-4) benefit from competition between deep nodes. The network is resilient at every layer.
