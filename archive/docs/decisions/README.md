# Decisions

Status: canonical

This folder is reserved for ADR-style records of important decisions.

Use it for choices that future contributors will ask "why?" about, such as:

- repo boundaries
- stack constraints
- deployment model
- trust model integration choices
- billing architecture choices

Suggested naming:

- `ADR-0001-repo-boundaries.md`
- `ADR-0002-deploy-via-github-actions.md`
