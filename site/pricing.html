Trust

Don't trust us. Verify us.

Every credit charge is cryptographically signed via Soma. You can prove every charge mathematically — no trust required.

Cryptographic receipts

Every charge gets a Soma birth certificate — signed by claw-net.org's DID, independently verifiable offline. If we ever overcharge you, it's provable.

Credits can't be devalued

Credits you already purchased are honored at the rate you paid. Price changes only affect new purchases, with 30 days advance notice.

You control the caps

Set your own daily and monthly spend limits. We can't charge more than you allow. Caps are enforced server-side before every API call.

15% transparent margin

We charge actual API cost + 15%. Same margin on every call, every model. No hidden fees, no variable markups, no fine print.

Full audit trail

Every charge includes: what was called, which model, token count, exact cost. Export your usage history anytime.

Open source

Pulse is open source. The billing code is auditable. You can see exactly how costs are calculated.
