Welcome to ClawNet

ClawNet is an API platform for AI agents. Ask a question in plain English, and ClawNet picks the best data sources, fetches everything in parallel, and returns a single structured answer — billed in credits.

You can also browse the Skill Marketplace to find community-built tools, or create your own and earn 85% of every credit spent on them.

Base URL
https://api.claw-net.org
Auth Header
X-API-Key: your_key
Format
JSON in, JSON out. UTF-8 everywhere.
Credits
Buy via Stripe or Solana USDC. Cached queries cost 10% of live price (min 0.1 credits).

Quick Start

Get from zero to your first API call in 3 steps. No SDK required — just curl (or any HTTP client).

Get an API Key
Sign up at claw-net.org/dashboard and purchase credits. You'll get a key that starts with cn_.
Ask a Question
Send any question to the orchestrate endpoint. ClawNet figures out which APIs to call, fetches the data, and returns an answer.
Read the Response
You get back an answer, the sources used, how many credits it cost, and how long it took.

Your First Request

curl -X POST https://api.claw-net.org/v1/orchestrate \
  -H "X-API-Key: cn_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"query": "What is the current price of SOL?"}'

What You Get Back

{
  "answer": "SOL is currently trading at $180.42 with a 24h change of +3.2%...",
  "sources": ["claw-token-price"],
  "creditsUsed": 4,
  "durationMs": 1240
}
That's it. One API call, one answer. The orchestrator handled endpoint selection, data fetching, and response formatting for you.

Core Concepts

Before diving into the API, here's how ClawNet works. Understanding these 5 concepts makes everything else click.

⚡
Credits
Credits are the currency of ClawNet. Every API call costs credits. Buy them with Stripe or USDC. Cached responses cost just 10% of the live price (min 0.1 credits). Check your balance anytime with GET /v1/auth/me.
🧠
Orchestration
Ask a question in plain English. The orchestrator parses your intent, picks the best API endpoints (from 340+ sources), fetches data in parallel, and returns one structured answer. No need to know which API to use — ClawNet handles it.
🔧
Skills
Skills are pre-built tools anyone can create and sell. Three types: Prompt (LLM-powered analysis), API Proxy (wraps an external API), and Data (structured data with smart caching).
🏪
Marketplace
The skill marketplace is where creators list their skills and buyers discover them. Creators earn 85% of every purchase. 15% goes to the platform. Star, rate, and review to help others find quality skills.
💾
Smart Caching
The first call to any data source fetches live data and caches it in Redis. Every call after that returns the cached version at 10% of the live cost (min 0.1 credits) until the cache expires. You always get told whether you hit cache or live.
💰
Budget Control
Set maxCredits and a strategy (cheapest, balanced, fastest, reliable) on any request. The optimizer swaps between 45+ equivalent API alternatives to hit your budget. Returns 402 if the plan exceeds your limit.

Authentication

Every API call needs authentication. There are two ways to authenticate, depending on where you're calling from.

API Key (most common)
Pass your key in the X-API-Key header. Use this for all server-to-server calls, scripts, bots, and agent integrations. This is what 99% of requests use.
Clerk JWT (browser only)
Some dashboard endpoints accept a Clerk session token via Authorization: Bearer {token}. This is only for the web dashboard — you won't need this for API integrations.

Example — API Key

curl https://api.claw-net.org/v1/auth/me \
  -H "X-API-Key: cn_your_key_here"
Your API key starts with cn_. Keep it secret. If compromised, regenerate it from the dashboard — your credits transfer to the new key automatically.

Errors & Rate Limits

All errors return JSON with an error field. Here's what each status code means and what to do about it.

CodeWhat It MeansWhat To Do
400Bad Request — something's wrong with your parametersCheck the request body matches what the endpoint expects
401Unauthorized — missing or invalid API keyAdd the X-API-Key header with a valid key
402Not enough credits for this requestTop up credits from the dashboard, or set a lower maxCredits budget
403You don't own this resourceCheck you're using the right API key
404Resource not foundDouble-check the skill ID or endpoint path
409Duplicate action (already starred, same idempotency key)Safe to ignore — the action already happened
429Rate limited — too many requestsWait for the reset time in X-RateLimit-Reset
500Something broke on our endRetry after a few seconds. If persistent, check status page

Error Response Example

{
  "error": "Insufficient credits",
  "code": "INSUFFICIENT_CREDITS",
  "creditsRequired": 5,
  "creditsAvailable": 2
}

Orchestration — Ask a Question

This is the main way to use ClawNet. Send a question in plain English, and the orchestrator figures out which APIs to call, runs them in parallel, and gives you one clean answer.

When to use this
You want to ask a question without knowing which specific API to call. Examples: "What is SOL's price and top holders?", "Is this token a rug pull risk?", "What's trending on crypto Twitter?"
POST /v1/orchestrate
Requires: X-API-Key

Body Parameters

NameTypeRequiredDescription
querystringYesYour question in plain English (max 2000 characters)
contextobjectNoExtra context to help the orchestrator (e.g. {"chain": "solana"})
pricingobjectNoBudget control — see below
Budget control with the pricing object

Set maxCredits to cap spending. The optimizer has 45+ alternative endpoints per capability — it will swap to cheaper ones to stay under budget.

{
  "query": "SOL price and holder analysis",
  "pricing": {
    "maxCredits": 5,
    "strategy": "cheapest"  // cheapest | balanced | fastest | reliable
  }
}
StrategyWhat It Does
cheapestPicks the lowest-cost endpoints. Best for non-urgent queries.
balancedBalances cost and speed. Good default.
fastestPicks the fastest endpoints regardless of cost.
reliablePicks endpoints with the highest uptime. Best for production.

Full Example

curl -X POST https://api.claw-net.org/v1/orchestrate \
  -H "X-API-Key: cn_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What is the current SOL price and who are the top holders?"
  }'

Response

{
  "answer": "SOL is trading at $180.42 (+3.2% 24h). Top 10 holders control 28% of supply...",
  "suggestedActions": ["Check whale movements", "View full holder distribution"],
  "sources": ["claw-token-price", "claw-token-holders"],
  "creditsUsed": 8,
  "durationMs": 1840
}

Streaming

When to use this
You want to show real-time progress to a user as the orchestrator works. Each step (planning, fetching, formatting) is streamed as a Server-Sent Event.
GET/v1/stream/orchestrate
Requires: X-API-Key (header or apiKey query param)

Query Parameters

NameTypeRequiredDescription
querystringYesYour question (URL-encoded)
apiKeystringNoAPI key as query param (alternative to header for EventSource)
strategystringNocheapest, balanced, fastest, reliable
maxCreditsnumberNoBudget cap

Events Emitted

EventWhat It Contains
startRequest acknowledged, orchestration beginning
planThe endpoints the orchestrator chose to call
stepEach API call result as it completes
doneFinal answer, sources, credits used
errorError details if something failed

JavaScript Example

const es = new EventSource(
  'https://api.claw-net.org/v1/stream/orchestrate?query=SOL+price&apiKey=cn_your_key'
);

es.addEventListener('step', (e) => {
  console.log('Step:', JSON.parse(e.data));
});

es.addEventListener('done', (e) => {
  const result = JSON.parse(e.data);
  console.log('Answer:', result.answer);
  es.close();
});

Skills — What Are They?

Skills are reusable tools that anyone can create and sell on ClawNet. Think of them like apps in an app store — but for AI agents. There are three types:

Prompt Skills
Powered by LLM orchestration. You write a prompt template with {{variables}}, and when someone invokes it, ClawNet fills in the variables, runs the prompt through the orchestrator, and returns the answer. Great for analysis, reports, and insights.
API Proxy Skills
Wraps any external HTTPS API. You set the URL, and when someone invokes your skill, ClawNet forwards the request and returns the response. Great for reselling or bundling API access.
Data Skills
Real-time crypto data as clean JSON. Prices, wallets, whales, yields — one query, structured output. ClawNet keeps data fresh automatically and caches it so repeat calls cost up to 90% less. As cheap as $0.0001 per call.

Using Skills

Found a skill you want to use? Here's how to invoke it. The endpoint depends on the skill type.

POST/v1/skills/:id/invoke

Execute a Prompt or API Proxy skill. Pass any required variables in the body. Credits are deducted based on the skill's price.

Requires: X-API-Key

Body

NameTypeRequiredDescription
variablesobjectNoKey-value pairs that fill in the skill's template variables
 
curl -X POST https://api.claw-net.org/v1/skills/token-sentiment/invoke \
  -H "X-API-Key: cn_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"variables": {"token": "SOL"}}'
Skills you own are free to invoke — you won't be charged credits for calling your own skills.

Data Skills

Data skills return structured JSON — not AI-generated text. You call them with a simple GET request. ClawNet handles caching automatically, so repeat calls are up to 90% cheaper. You don't need to manage any caching logic yourself.

GET/v1/skills/:id/query

Query a data skill. Any query parameters you pass are forwarded to the backing data source.

Requires: X-API-Key
curl "https://api.claw-net.org/v1/skills/price-oracle-data/query?token=SOL" \
  -H "X-API-Key: cn_your_key_here"

Cache Duration Reference

When you create a data skill, the updateFrequency controls how long responses are cached. Cached calls cost 90% less (min $0.0001). You can use presets or custom durations:

SettingCache DurationBest For
realtime60 secondsLive prices, order books, gas fees
hourly1 hourMarket summaries, holder stats
daily24 hoursAnalytics, yield data, risk scores
weekly7 daysReports, historical trends
static30 daysReference data, contract metadata
5m, 30m, 2h, 3d, etc.CustomAny duration — use s, m, h, or d suffix

Composite Skills

Chain multiple skills into higher-order workflows. Composites call sub-skills in sequence or parallel with output piping between steps. Limits: max 5 dependencies, max depth 3 (composites-of-composites), max 10 leaf invocations per execution.

POST/v1/skills

Create a composite skill by setting skillType: "composite" and providing a dependencies array that defines the execution graph.

Requires: X-API-Key

Dependencies Example

[
  {
    "skillId": "token-price",
    "paramMapping": { "token": "{{token}}" },
    "outputKey": "price"

  {
    "skillId": "sentiment",
    "paramMapping": { "query": "{{token}}" },
    "outputKey": "sentiment"
  }
]
POST/v1/skills/:id/invoke

Invoke a composite skill. Each sub-skill runs in dependency order. Returns per-step results and a full cost breakdown.

Dynamic Pricing

Skill creators can configure surge, volume, and off-peak pricing. Prices adjust automatically based on demand — no manual intervention required.

POST/v1/skills

Set dynamic pricing via the pricingConfig object when creating or updating a skill.

Requires: X-API-Key

Pricing Config

{
  "pricingConfig": {
    "surge": {
      "enabled": true,
      "threshold": 100,
      "multiplier": 2.5,
      "maxMultiplier": 5.0
    },
    "volume": {
      "enabled": true,
      "tiers": [
        { "minCalls": 100, "discountPct": 10 },
        { "minCalls": 500, "discountPct": 25 },
        { "minCalls": 1000, "discountPct": 50 }
      ]
    },
    "offPeak": {
      "enabled": true,
      "utcHours": [2, 3, 4, 5, 6],
      "discountPct": 20
    }
  }
}

Surge: Multiplier up to 5x when demand exceeds threshold calls per hour. Volume: Monthly call tiers with up to 50% discount. Off-peak: UTC hour windows with reduced pricing.

Output Contracts

Define a JSON Schema that skill outputs must conform to. Agents can validate trust before paying — every invocation response includes whether the output matched the contract.

Set an output contract when creating a skill via the outputContract field. Uses standard JSON Schema.

Requires: X-API-Key

Output Contract Example

{
  "outputContract": {
    "type": "object",
    "required": ["price", "symbol"],
    "properties": {
      "price": { "type": "number" },
      "symbol": { "type": "string" }
    }
  }
}
POST/v1/skills/:id/invoke

When invoking a skill with an output contract, the response includes outputContractValid: true/false so agents can verify conformance. Provider info shows hasOutputContract: true in skill listings.

Requires: X-API-Key

  "outputContractValid": true,
  "credits": 1.5
