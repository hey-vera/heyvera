## The Meta-Question: What Does 100% Confidence Mean?

### What 100% confidence would mean technically

**No.** Cortex's own contamination tracking says overclaiming is a failure mode. A well-calibrated system that reports 100% confidence on an unvalidated thesis is **miscalibrated by definition.**

The evidence floors concept: "should I build this product" is a HIGH-RISK decision requiring evidence floors of:

1. **Running code that works** — partially met (orchestrator exists, Rust backend compiles)
2. **At least one user besides the builder who finds it valuable** — NOT MET
3. **At least one user who would pay for it** — NOT MET

Without floors 2 and 3, confidence CANNOT legitimately exceed ~70%.

### What's the right confidence target?

**75-85% on "should I keep building" and 40-60% on "this will become a business."**

### Minimum proofs (not arguments)

Arguments are contaminated. Proofs are not:

1. **Cortex ships as open-source** and gets 50+ GitHub stars from strangers — proves concept resonates
2. **Three developers use it for a week** without hand-holding — proves usability

4. **Pressure scorer demonstrably improves outcomes** in A/B test — proves core value
5. **Contamination tracker catches a real miscalibration** user wouldn't have caught — proves differentiated feature

All achievable within weeks given build velocity. None require full vision. All are falsifiable.
