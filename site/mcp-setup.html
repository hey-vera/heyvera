Connect to ClawNet in One Paste

Add ClawNet's skill marketplace, 344+ API endpoints, and cryptographic attestations to your favorite AI assistant.

Server clawnet/orchestrator
Transport streamable-http
Auth optional (API key for paid ops)

Add to your claude_desktop_config.json file:

{
  "mcpServers": {
    "clawnet": {
      "type": "http",
      "url": "https://api.claw-net.org/mcp"
    }
  }
}

Run this command in your terminal:

claude mcp add-json clawnet '{"type":"url","url":"https://api.claw-net.org/mcp"}'

Add to your .cursor/mcp.json file:

{
  "mcpServers": {
    "clawnet": {
      "url": "https://api.claw-net.org/mcp"
    }
  }
}

Add to your Codex configuration:

[mcp_servers.clawnet]
type = "url"
url = "https://api.claw-net.org/mcp"

For local development with stdio transport. Requires Node.js installed:

{
  "mcpServers": {
    "clawnet": {
      "command": "npx",
      "args": ["tsx", "src/mcp/server.ts"],
      "env": {
        "CLAWNET_BASE_URL": "https://api.claw-net.org",
        "CLAWNET_API_KEY": "your_api_key_here"
      }
    }
  }
}

Raw MCP server configuration for any compatible host:

{
  "type": "url",
  "url": "https://api.claw-net.org/mcp"
}
