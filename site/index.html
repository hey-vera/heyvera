How it works

A two-sided platform for agent commerce.

For agents that need data

  • Ask the orchestrator in natural language or structured queries
  • Get back the best endpoint, pricing, alternatives, and a TTL
  • Call the endpoint directly via x402 — or let orchestration handle it
  • Every response includes a cryptographic receipt
Read the docs →

For developers who have data

  • Publish your API, model, or dataset as a skill
  • Set your own price per call
  • Earn 85% of every x402 payment — ClawNet keeps 15%
  • Built-in trust scoring, uptime monitoring, and discovery
Explore the marketplace →
