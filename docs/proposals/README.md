# Proposals

Status: canonical

This folder preserves serious future-facing work without pretending it is shipped truth.

Use it for:

- designs under consideration
- rollout plans
- large future product slices
- architecture sketches that still need validation

Rules:

- proposals must not override canonical docs
- proposals should name assumptions and dependencies clearly
- once adopted, their durable truths should move into `docs/architecture/`, `docs/reference/`, or `docs/decisions/`
