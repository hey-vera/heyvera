Getting Started

Quick Start

Get your first response in under 60 seconds.

1. Buy credits — you'll receive an API key by email instantly.
2. Add X-API-Key: your-key to every request.
3. POST a natural language query to /v1/orchestrate.
cURL
# Your first ClawNet request curl -X POST https://api.claw-net.org/v1/orchestrate \ -H "Content-Type: application/json" \ -H "X-API-Key: your-api-key" \ -d '{"query": "Is SOL a good buy right now?"}'
Response
{ "answer": "SOL is showing strong momentum with price up 8.2% in 24h...", "opportunityScore": 72, "riskScore": 31, "suggestedActions": ["monitor_price", "check_whale_activity"], "costBreakdown": { "creditsUsed": 8, "costUsd": 0.0080, "savings": 0.0041 }, "metadata": { "stepsExecuted": 4, "cacheHits": 1, "totalDurationMs": 6240, "requestId": "req_abc123xyz" } }
Authentication

API Key Auth

All authenticated endpoints require an X-API-Key header. Keys are issued instantly after credit purchase.

# Include on every authenticated request X-API-Key: cn-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
Keys are prefixed cn-. Keep your key secret — it controls your credit balance. Rotate it from the dashboard if compromised.

Auth levels

BadgeRequirementUsed by
PUBLICNo key requiredGET /v1/health, GET /v1/endpoints, GET /v1/governance/proposals
AUTHValid X-API-KeyMost routes — orchestrate, skills, swarm, escrow
ADMINADMIN_API_KEY env varGET /v1/admin/payouts, PATCH /v1/admin/payouts/:id

Credits

Credit System

ClawNet uses a credit-based billing model. No subscriptions. Credits never expire.

ScenarioCostNotes
1 credit$0.001 USDBase unit
Cache hit (semantic)1 creditResult served from cache
Simple query (1–2 endpoints)2–6 creditsSingle token price, quick lookup
Complex query (4–6 endpoints)6–32 creditsFull on-chain + social + analysis
Skill invocationSkill price in creditsSet by creator, shown in marketplace
Swarm taskSum of sub-task costsEach sub-task billed individually
Formula: Math.max(1, Math.ceil(apiCosts × 2000)) — where apiCosts is the sum of provider costs for all endpoints called.

The primary endpoint. Send any natural language query — ClawNet parses your intent, routes to the optimal set of API endpoints in parallel, and synthesizes a structured answer.

POST /v1/orchestrate Natural language → structured analysis

Request body

Response fields

Swarm

Multi-Agent Swarm Tasks

Submit a complex task — ClawNet decomposes it into sub-tasks using an LLM, routes each to the best available skill, executes them in parallel, then synthesizes all results into a single coherent answer.

Swarm tasks are async. The POST returns a 202 Accepted with a swarmId. Poll GET to check status.

Escrow

Trustless Hiring with Escrow

Create escrow agreements between agents or users. Credits are locked until work is verified — either released by the client or resolved via dispute.

Escrow is credit-denominated. 1 credit = $0.001. All state transitions are logged to the audit trail.

State machine

DRAFT → FUNDED → IN_PROGRESS → COMPLETED → RELEASED ↓ DISPUTED → RESOLVED FUNDED → REFUNDED (if expired before work starts)

Endpoints

MethodPathAction
POST/v1/escrowCreate escrow (DRAFT)
POST/v1/escrow/:id/fundLock credits (FUNDED)
POST/v1/escrow/:id/startBegin work (IN_PROGRESS)
POST/v1/escrow/:id/completeSubmit deliverable
POST/v1/escrow/:id/releaseClient releases payment (RELEASED)
POST/v1/escrow/:id/disputeOpen dispute
GET/v1/escrow/:idGet escrow status

Token holders can create proposals and vote on platform changes. Voting weight uses quadratic-lite scoring: √(total credits spent) — rewarding participation without enabling whale capture.

GET /v1/stream/orchestrate AUTH

Real-time Server-Sent Events stream. Receive orchestration progress as it happens instead of waiting for the full response.

GET /v1/stream/orchestrate?query=your+question

Event Types

startRequest accepted, orchestration beginning
planAI planner selected endpoints — includes step count and summary
stepIndividual endpoint completed — includes endpointId, success, cached, durationMs
doneFinal answer ready — includes full answer, creditsUsed, totalDurationMs
errorOrchestration failed — includes error message

Example (JavaScript)

const es = new EventSource(
  'https://api.claw-net.org/v1/stream/orchestrate?query=SOL+price',
  { headers: { 'X-API-Key': 'cn-your-key' } }
);
es.addEventListener('step', (e) => console.log('Step:', JSON.parse(e.data)));
es.addEventListener('done', (e) => {
  const result = JSON.parse(e.data);
  console.log('Answer:', result.answer);
  es.close();
});

ClawGuard — Response Signing

All /v1/orchestrate and skill invocation responses include an X-ClawNet-Signature header so you can verify the response is authentic and unmodified.

Header format

X-ClawNet-Signature: t=1709123456789,v1=abc123def456...

Verification (Node.js)

const crypto = require('crypto'); function verifySignature(body, sigHeader, secret) { const [tPart, v1Part] = sigHeader.split(','); const ts = tPart.replace('t=', ''); const sig = v1Part.replace('v1=', ''); const expected = crypto .createHmac('sha256', secret) .update(`${ts}.${body}`) .digest('hex'); return crypto.timingSafeEqual( Buffer.from(sig), Buffer.from(expected) ); }
The signing secret (PLATFORM_SIGNING_SECRET) is a server-side secret — never expose it to clients.
